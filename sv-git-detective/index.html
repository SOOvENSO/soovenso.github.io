Git Detective

Une clé de test a disparu du catalogue. Retrouvez le commit qui l’a introduite et celui qui l’a retirée.

Télécharger le dossier ↓

Préparer l’enquête

Décompressez le dossier. Avec Git installé, ouvrez un terminal dans le dossier contenant catalogue.bundle.

git clone -b main ./catalogue.bundle catalogue
cd catalogue
git log --oneline

Les quatre commits sont fournis dans le bundle. Le fichier START.txt contient le guide en darija.

Comparer deux états du catalogue

Inspectez le modèle de configuration actuel. Remontez ensuite son historique et identifiez les deux changements. Consignez leurs identifiants dans RAPPORT.txt.

Indice 1 · repérer les fichiers modifiés
git log --oneline --stat
Indice 2 · lire les modifications
git log -p -- catalogue.env.example

Un + indique une ligne ajoutée et un − une ligne retirée. Appuyez sur q pour quitter la lecture.

Vérifier votre découverte

Saisissez le flag fictif trouvé dans le bundle. La vérification se fait dans votre navigateur.

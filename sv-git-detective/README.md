# SV Git Detective

Un exercice de revue d’historique Git par Khalid Aslaoui (SOOVENSO). Une boutique fictive a retiré une clé de test de son modèle de configuration. Retrouvez la trace de son introduction et de son retrait, puis documentez les preuves.

[Ouvrir le laboratoire](https://soovenso.github.io/sv-git-detective/)

1. Téléchargez le dossier depuis le laboratoire puis décompressez-le.
2. Avec Git installé, suivez START.txt pour examiner les quatre commits de catalogue.bundle.
3. Utilisez le vérificateur de flag et complétez RAPPORT.txt. Les indices sont facultatifs.

La page embarque l’archive et l’illustration. Aucun compte ni service distant n’est nécessaire pour examiner le dépôt de démonstration.
